# SOCKS5 Lab Configurations

Configuration examples for the SOCKS5 experimental labs are stored here.

Credentials, private addresses, authentication secrets, VPN keys, and other
sensitive values must not be committed.

The first planned configuration is:

```text
hev-socks5-server.example.yml
```

It will be introduced only after the server configuration has been tested
in the controlled LAB-001 environment.
